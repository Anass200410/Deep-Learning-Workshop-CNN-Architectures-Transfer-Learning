# 🧠 Deep Learning Workshop – CNN Architectures & Transfer Learning

## 📌 Overview

This repository contains practical work carried out during a Deep Learning workshop focused on image classification using Convolutional Neural Networks (CNNs).

The main objective is to experiment with different CNN architectures, understand their behavior during training, and compare two approaches:

1. **Training from Scratch:** Building and training CNN models using randomly initialized weights.
2. **Transfer Learning:** Reusing pre-trained CNN architectures and adapting them to a new classification task.

The workshop explores how different architectures and training strategies affect model performance, convergence, and generalization.

## 🎯 Objectives

- Understand the fundamentals of Convolutional Neural Networks.
- Implement and train multiple CNN architectures (Vgg16 , Resnet 50, Inception v3).
- Experiment with different network configurations.
- Apply Transfer Learning using pre-trained models.
- Perform fine-tuning to improve classification performance.
- Compare models using quantitative evaluation metrics.
- Analyze overfitting and generalization through learning curves.

## 🏗️ Models and Experiments

### 1. CNN Training from Scratch

Implementation and training of different CNN architectures with randomly initialized weights.

### 2. Transfer Learning

Using pre-trained CNN architectures to benefit from previously learned visual features.

Experiments include:
- Feature Extraction: Freezing the pre-trained convolutional base and training a new classification head.
- Fine-Tuning: Unfreezing selected layers and retraining them to adapt the model to the target dataset.

### 3. Model Evaluation

Models are evaluated using:
- Accuracy
- Confusion Matrix
- Training and Validation Loss
- Training and Validation Accuracy

## 📊 Results and Analysis

The experiments aim to compare the performance of CNN architectures trained from scratch against pre-trained models adapted through Transfer Learning.

The analysis focuses on:
- Training efficiency and convergence speed.
- Classification performance.
- Generalization on unseen data.
- The impact of fine-tuning on model performance.
